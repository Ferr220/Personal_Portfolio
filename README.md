# Personal Portfolio

Personal portfolio website for Fernando Jose Colombo Rivera.

## Live Overview

This project is a clean, single-page portfolio built with HTML and CSS to showcase:

- Personal profile and introduction
- Selected projects with live and source links
- Experience, education, and skills
- Resume access
- Contact details, GitHub, and FlowTech links

## Tech Stack

- HTML5
- CSS3

## Project Structure

```text
Personal_Portfolio/
|- index.html
|- style.css
|- README.md
|- Work Resume.pdf
`- IMAGES/
```

## Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Ferr220/Personal_Portfolio.git
```

2. Enter the project folder:

```bash
cd Personal_Portfolio
```

3. Open `index.html` in your browser.
